# UC-00 マスキング確認（Windows / 223教室・1台）

既存の `tools/camera_preview.py` を使用します。依存関係の追加はありません。
範囲は**推論前**にOpenCV画像の画素を黒（0）にします。指定しない場合は従来と同じ画像で検知します。
設定ファイルは元映像のピクセル座標です。解像度が変わった場合は停止し、範囲を再設定します。
人や検知枠がマスク境界をまたぐと、正しく検知していた人も消える可能性があります。

## 1. 自分で範囲を選ぶ（DB保存なし）

リポジトリのPowerShellで実行します。

```powershell
.\.venv\Scripts\python.exe tools\camera_preview.py --select-mask .camera-runtime\masks\223-v1.json
```

Piの配信から取得した1フレームを表示します。検知対象から除外したい範囲をマウスでドラッグし、
EnterまたはSpaceで1領域を確定します。複数領域を追加できます。Escで領域選択を終了し、
黒塗りの確認画面で **S** を押すと保存、EscまたはQでキャンセルします。
未選択でSを押すと空の範囲を保存します。既存設定は上書きしません。変更時は `223-v2.json` など別名を使ってください。
この操作ではYOLO推論もDB保存も行いません。座標を自動決定しません。

JSON形式は `width`, `height`, `rectangles` です。
`rectangles` の各要素は `[左上X, 左上Y, 幅, 高さ]` の整数です。
1280×720で範囲未指定の場合は `{"width":1280,"height":720,"rectangles":[]}` です。

## 2. 同一フレームの前後を比較（DB保存なし）

```powershell
.\.venv\Scripts\python.exe tools\camera_preview.py --mask-config .camera-runtime\masks\223-v1.json --compare-mask --max-images 20
```

左がマスキング前、右がマスキング後です。それぞれ人数・検知枠を表示します。
同じ取得フレームをコピーし、同一のconfidence/NMS IoU/画像サイズで2回推論します。
既定値は **confidence=0.25、NMS IoU=0.7、imgsz=640、personのみ** です。
`--compare-mask` と `--save-db` の併用はエラーです。DB接続・保存処理は呼びません。
終了はプレビューでQ/Esc、またはPowerShellでCtrl+Cです。

最初の比較と、前後いずれかの人数が変化した比較をローカル保存します。
保存先は `.camera-runtime/captures/mask-comparison-日時-識別子/` です。
1実行あたり最大20組（`--max-images`で変更可）で、上限後もプレビューは続きます。
過去の実行結果は削除・上書きしません。枠だけが変化し人数が同じ場合は追加保存しません。
任意のタイミングで1組を記録するには、停止後に以下を別実行します。

```powershell
.\.venv\Scripts\python.exe tools\camera_preview.py --mask-config .camera-runtime\masks\223-v1.json --compare-mask --headless --max-frames 1 --max-images 1
```

各組には比較画像 `.jpg`、元フレーム `.npz`、結果 `.json` を保存します。
JSONには計測日時、使用したマスク座標、設定、前後の人数・枠・confidenceを記録します。
実人数は推測せず `actual_count: null` としています。目視確認後にこの値と `notes` を記入してください。
