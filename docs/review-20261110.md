## データ0件・通信エラーを安全に見せる

運用MySQLの停止・データ削除・`.env` の変更は不要です。次のPowerShellコマンドは、別ポート8001で一時的なメモリ内SQLiteを使います。運用画面の8000番とは別環境です。

最初は `$reviewScenario = "empty"` で起動し、`http://127.0.0.1:8001/` を開きます。TOP → 予測 → 曜日別と移動し、各画面の「対象期間のデータが存在しません」を確認します。

```powershell
$reviewScenario = "empty"
@'
import os
import sys
from contextlib import nullcontext
from unittest.mock import patch

os.environ['DJANGO_SETTINGS_MODULE'] = 'config.test_settings'
import django
django.setup()
from django.conf import settings
from django.core.management import call_command
from django.db.utils import OperationalError
from crowd_app.models import LocationMaster

scenario = sys.argv[1]
if scenario not in ('empty', 'error'):
    raise SystemExit('Use empty or error')
settings.ALLOWED_HOSTS = ['127.0.0.1', 'localhost']
call_command('migrate', verbosity=0, interactive=False)
LocationMaster.objects.create(name='レビュー専用・記録なし', capacity=41)
failure = patch('crowd_app.models.LocationMaster.objects.order_by',
                side_effect=OperationalError(2003, 'review simulation'))
with failure if scenario == 'error' else nullcontext():
    call_command('runserver', '127.0.0.1:8001', use_reloader=False,
                 use_threading=False, insecure_serving=True)
'@ | .\.venv\Scripts\python.exe - $reviewScenario
```

データ0件の確認が終わったら **Ctrl+C** で止めます。先頭を `$reviewScenario = "error"` に変えて同じコマンドを実行し、8001番のページを再読み込みします。「エラーが発生しました」と表示され、HTTPステータスは503になります。これはDB接続失敗を意図的に再現する実演です。実際のカメラ・MySQLとの接続成功の実演と区別して説明します。

終了は **Ctrl+C**。一時データはプロセス終了時に消え、運用データは変わりません。`config.test_settings`、`use_reloader=False`、`use_threading=False` は変更せずに使ってください。

## 予測の計算方法

1. 本日より前の、同じ曜日・同じ時間帯の記録平均を基準にします。MySQLのタイムゾーンテーブルには依存しません。
2. 当日の直近30分に保存された `source='camera'` の記録だけを補正に使います。ダミー・未確認・別の場所・未来の記録は補正から除外します。
3. 実測を取得した時間帯の過去平均と、直近実測の人数を比較します。
4. 過去の時間帯別平均に、当日の相対的な人数の水準を半分だけ反映します。

過去の比較値が正なら、補正倍率は `0.5 + 0.5 ×（直近実測の人数合計 ÷ 対応する過去平均の合計）` です。
比較値がすべて0なら、将来の過去平均へ直近実測平均の半分を加算します。最終値は0以上、小数第1位に丸めます。
比較できる実測がない場合は過去平均のままです。過去記録のない将来の時間帯には予測点を作りません。

13:20時点では、基準データがある14時以降の予測点を表示します。実測やダミーの行を未来の予測としてそのまま表示するものではありません。
閲覧時に計算し、予測値をDBに書き込みません。精度評価・機械学習は未実施です。
